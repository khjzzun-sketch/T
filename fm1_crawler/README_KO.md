# 판타지마스터즈1 카드 수집기

이 저장소의 Android 앱 빌드 workflow와 분리된 카드 DB 수집 workflow입니다.

## 실행
GitHub 저장소의 **Actions → FM1 Card Database Crawler → Run workflow**에서 실행합니다. 매주 일요일에도 자동 실행됩니다.

## 수집 방식
1. `/cardlist`를 Chromium으로 열고 카드 링크 및 무한 스크롤 목록을 수집합니다.
2. 브라우저가 받은 JSON 응답에서 카드 ID 후보를 추가 추출합니다.
3. 사용자 제공 ID 세 개의 앞 10자리 각각에 대해 마지막 숫자 0~9를 대입해 보조 확인합니다.
4. 유효한 상세 페이지의 본문 텍스트, 메타 설명, 이미지 후보, HTML 원본을 저장합니다.
5. SQLite와 이미지/원본 HTML/요약 파일을 Actions artifact로 보관합니다.

## 주의 및 검증
- 11자리 ID의 앞 10자리가 생성 시각이라는 해석은 아직 가설입니다. 따라서 현재 구현은 제공된 세 접두어의 마지막 숫자만 보조 검사하며, 전체 11자리 공간을 무차별 탐색하지 않습니다.
- 카드목록이 실제로 로드되지 않거나 사이트가 봇 요청을 차단하면 결과가 비거나 일부만 수집될 수 있습니다.
- HTTP 200 응답만으로 카드임을 확정하지 않습니다. SPA 공통 오류 페이지는 제외하고 원본 HTML과 본문 텍스트를 남깁니다.
- 현재 단계에서는 페이지의 실제 DOM 구조/API를 실행 환경에서 검증하지 못했습니다. 카드별 속성·레벨·희귀도·AP/DP/HP 등 필드의 정밀 매핑은 실제 응답을 확인한 뒤 보완해야 합니다.
- 저작권이 있는 일러스트는 개인 도감/연구 목적의 로컬 보관으로만 취급하고, 외부 공개 배포 전에 권리 상태를 확인하세요.

## 결과물
Actions 실행 결과의 `FM1-card-database` artifact에 다음 파일이 포함됩니다.
- `FM1_Master_Database.db`
- `images/`
- `raw/` (카드목록 및 상세 HTML, JSON 응답)
- `discovered_ids.txt`
- `crawl_summary.json`

현재 workflow는 수집 자동화의 첫 실행 기반입니다. 실제 카드 전체 수집 완료를 보장하는 완성 DB는 아닙니다.
